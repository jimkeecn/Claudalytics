在动手构建中学习 Microsoft Agent Framework

你将从零构建一个真实的后端 .NET 智能体服务——但你不会照搬一份已完成的 构建顺序。你将亲历它的演进：先写出朴素的版本，撞上它的瓶颈，再重构成 真正的版本。其中有几件产物是被刻意丢弃的。这正是重点所在。

⚡ 验证仪式

每一课都用 dotnet run -- --environment Testing 启动。那个 -- 分隔符至关重要——没有它，dotnet 会停留在 Production（昂贵的模型、没有调试日志）。整个课程的第一道关卡：证明控制台 打印出 Hosting environment: Testing。

读者对象：熟悉 ASP.NET minimal API 和基础 SQL 的 .NET 开发者。不假设你有任何智能体（agent）或 LLM 框架的经验。成本控制是结构性的——模块 B 运行起来零成本，且每一个 LLM 关卡都跑在固定使用 Haiku 的 Testing 环境上。
