Learn Microsoft Agent Framework by Building

You build a real backend .NET agent service from scratch — but you don't retrace a finished build order. You live the evolution: build the naive version, hit its breaking point, refactor into the real one. Several artifacts are deliberately thrown away. That is the point.

⚡ The verification ritual

Every lesson is launched with dotnet run -- --environment Testing. The -- separator is load-bearing — without it dotnet stays in Production (expensive models, no debug logs). First gate of the whole curriculum: prove the console prints Hosting environment: Testing.

Audience: a .NET developer comfortable with ASP.NET minimal APIs and basic SQL. No prior agent or LLM-framework experience assumed. Cost discipline is structural — Module B costs nothing to run, and every LLM gate runs on the Haiku-pinned Testing environment.
