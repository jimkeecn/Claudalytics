**v2.1.281 — no impact.** This release is entirely CLI UI, session-resume, proxy/gateway, MCP-connection, vim-mode, and dialog fixes, plus Claude apps gateway config additions. None of it changes the Claude Code hook-event contract, tool schemas, or the OTLP telemetry schema/env-vars that Claudalytics hardcodes.

Checked (all unaffected): hook event names (`hook-events.ts`, `field-mapping.ts` `EVENTS_TO_EMIT`, `plugin/hooks/hooks.json`); tool names & `tool_response` fields (`field-mapping.ts`, ClickHouse MVs 003/005/007/011); OTel service/table/attribute names (`otel-emitter.ts`, `otel-collector-config.yaml`); OTel env-vars and health-check schema (`plugin/skills/init-claudalytics/SKILL.md`).

Notes (informational, no code change needed):
- The new `telemetry.resource_attributes` is a **Claude apps gateway** config key — not Claude Code's `OTEL_RESOURCE_ATTRIBUTES` env var used by the init skill. Different surface.
- New MCP "URL-mode elicitation" adds a new `mode` value on `Elicitation`/`ElicitationResult`; the repo already captures `mode` generically (`field-mapping.ts:342,350`), so ingestion is unaffected.
