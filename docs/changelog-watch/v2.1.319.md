# [CC Changelog] 2.1.319 — no impact

**Source:** https://code.claude.com/docs/en/changelog (version 2.1.319, released 2026-11-06)
**Scanned:** 2026-11-08

**v2.1.319 — no impact**

No changes in this release rename or remove a hook event name, a tracked tool name
(Read / Edit / Write / Agent / WebSearch / WebFetch / Bash), an OTel attribute key, an
`OTEL_*` env var, or the health-check response schema. The release is almost entirely
Claude apps gateway, auto-mode, permissions-config, CLI/UX, and `/claude-api` tooling.

Hook-adjacent items reviewed and cleared:

- **PostToolUse hooks now run (≤10s) on tool calls that finish after an interrupt** — additive;
  `hooks-server` already forwards `PostToolUse` / `PostToolUseFailure` (with `is_interrupt`),
  so these extra events are captured automatically. No code change needed.
- **Removed `shortcuts_list` / `shortcuts_execute`** (Claude-in-Chrome tools) — not referenced
  anywhere in `docker-stack/` or `plugin/`; the repo only special-cases the 7 tools above.
- **New `permissions.denyInsteadOfPrompting` setting** — at most produces more `PermissionDenied`
  events, which `field-mapping.ts` and the MVs already handle.
