## Notable non-impacting items (Info / Low only)

- **"Removed `shortcuts_list` and `shortcuts_execute` from the Claude in Chrome tools."** — These are Claude-in-Chrome MCP tools, not Claude Code core tool names. The repo only special-cases Read/Edit/Write/Agent/WebSearch/WebFetch/Bash in `field-mapping.ts`; `shortcuts_*` was never referenced. No impact.
- **"Telemetry: `claude_code.session.count` counted unclaimed `prewarm()` processes."** — Native OTel metric fix. The dashboard (`otel-overview.json`) does **not** query `claude_code.session.count` (it uses `lines_of_code.count`, `active_time.total`, `commit.count`), so corrected counts do not change any panel. No impact.
- **"PostToolUse hooks run (up to 10 seconds) on tool calls that finish after an interrupting message."** — Benign data-accuracy improvement for `007_blocked_tools_mv.sql`: a few interrupted tool calls that previously left a `PreToolUse` with no matching `PostToolUse` (counted as `completed=0` → blocked) may now resolve to `completed=1`. The `is_interrupt` path on `PostToolUseFailure` already covers interrupt handling; no code change needed.
- **`permissions.denyInsteadOfPrompting`** (new setting) — When enabled by a user, a call that would wait on a prompt is denied outright, slightly shifting the mix of `PermissionRequest` vs `PermissionDenied` events. Both events are already captured in `EVENTS_TO_EMIT` / `field-mapping.ts`. No code change needed.
