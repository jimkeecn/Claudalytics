### Details

#### 🟢 New OTel attributes: `anthropic.plan`, `anthropic.seat_type`, `anthropic.provider`, `anthropic.custom_base_url` (Improvement)

Claude Code now attaches these four attributes to its **native** OTel metrics, events and spans (the telemetry `init-claudalytics` enables via `CLAUDE_CODE_ENABLE_TELEMETRY=1` → `OTEL_EXPORTER_OTLP_ENDPOINT=http://localhost:4317`). They arrive on `claudalytics.otel_metrics` / `otel_logs` / `otel_traces`.

- **Why it is not a break:** the collector writes attributes into Map columns (`Attributes[...]`, `ResourceAttributes[...]`) with `create_schema: true`. Unknown keys are stored transparently, exactly like the existing `Attributes['user.email']` lookup in `otel-overview.json` (e.g. the `claude_code.lines_of_code.count` panel). No schema migration or MV change is forced.
- **Opportunity:** these are useful cost/usage dimensions. For example, the existing cost and lines-of-code panels could add a breakdown by `Attributes['anthropic.provider']` (anthropic / bedrock / vertex) or `Attributes['anthropic.plan']`, mirroring the existing `project.name` / `session.id` template variables.
- **Caveat:** values populate only for sessions on Claude Code ≥ 2.1.317; older sessions leave these keys empty, so any new panel should tolerate blank values.
