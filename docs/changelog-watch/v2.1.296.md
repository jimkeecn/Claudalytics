## Details

### 🟢 git_commit_id now reliably emitted on tool_result events (bugfix #38) — Improvement

**What changed upstream:** OTel `tool_result` events previously dropped `git_commit_id` after a quieted or directory-scoped commit (`git commit -q`, `git -C <dir> commit`). 2.1.296 fixes this, so tool_result log events now carry the commit id in those cases.

**Repo state:** `grep` for `git_commit_id` / `commit_id` returns **no matches** in repo code. The native Claude Code OTLP stream lands all log attributes into the generic `otel_logs.LogAttributes` map (`001_init_schema.sql`), so the fixed/added attribute is captured automatically with **no code change required**. The repo's commit analytics today use the `claude_code.commit.count` metric from `otel_metrics_sum` (dashboard panels "Commits vs Cost per Day [KAN-31]" and "Per-User Cost Leaderboard [KAN-36]"), not the per-tool_result `git_commit_id`.

**Opportunity (not a break):** With `git_commit_id` now reliable on tool_result events, the repo could add a view/panel correlating specific file-mutation tool_results with the commit that captured them (e.g. "edits per commit", "uncommitted edit churn"). This is net-new analytics, optional.

### 🟢 Sonnet 5.5 cache-read price $0.20 → $0.10 /M tokens — Info

**What changed upstream:** `/cost`, status line, `--max-budget-usd` and the SDK now price Sonnet 5.5 cache reads at $0.10/M (was $0.20). Claude Code computes and emits the final `cost_usd` on `api_request` events.

**Repo state:** All cost panels read `LogAttributes['cost_usd']` directly (verified at `otel-overview.json:177`, `:448`, `:1317`, `:1363`, `:1575`). There is no pricing table or per-token cost math in the repo to update — the change is fully upstream.

**Watch-out:** Historical vs. post-upgrade cost comparisons will show a **discontinuity** (lower cost-per-1K and lower total spend) for Sonnet-5.5-heavy, cache-read-heavy workloads, purely from the price cut — not a usage change. Worth a note for anyone reading the "$ per 1K Output Tokens [KAN-38]" / pricing-drift panel across the upgrade boundary.
