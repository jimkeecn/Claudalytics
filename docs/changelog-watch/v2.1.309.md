**Source:** https://code.claude.com/docs/en/changelog (entry `2.1.309`, released 2026-10-22)
**Scanned:** 2026-10-22

**v2.1.309 — no impact.** No change in this release touches the Claude Code internals that Claudalytics hardcodes (hook event names/fields, OTel attribute keys, tool names, permission-mode/notification-type enums, or the plugin health-check schema). The release is CLI/VSCode/sandbox/cloud-UX mechanics plus bundled-skill updates (dataviz APCA, `/claude-api`). The only item touching captured behavior — `sed -i` now running as a standard Bash command instead of a simulated edit-preview — does not change telemetry: `sed -i` is still a `Bash` tool invocation, so `tool_name` stays `Bash` and `005_file_mutations_mv.sql` continues to capture it; the change affects the permission prompt and `/rewind` only. No ingestion, materialized-view, dashboard, or plugin action required.
